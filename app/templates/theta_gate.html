Theta Validation Rules (Level 1)

  1. SMEs rank all survived parameters independently. Anonymous.
  2. System computes variance (sigma squared) per parameter. If sigma squared is less than or equal to theta, accept average, normalize into Wi, lock.
  3. If sigma squared exceeds theta, Dangerous Disagreement: Delphi re-rank round (SMEs see anonymous peer distribution).
  4. Re-rank rounds surface ONLY divergent parameters. Converged parameters are locked and never re-opened.
  5. Maximum 3 rounds. If sigma squared still exceeds theta after round 3, Legitimate Divergence: escalated to leadership.
  6. Exit: All parameters converged, weights locked, proceed to KPI mapping (Step 4).
