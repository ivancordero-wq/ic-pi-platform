10. Data Collection Brief

Instructions for the client data team to populate the Standard Data Template.

What to do:

  1. Open the Standard Data Template (Excel file provided separately)
  2. For each KPI row, read the Formula column (Section 9 above)
  3. Compute the raw value from your data systems using that formula
  4. Enter the raw value in the Raw Value column (use the unit shown)
  5. Fill in Measurement Period
  6. Fill in Evidence Source (which system the data came from)
  7. Return the completed template to your IC-pi consultant

Important:

  • Enter RAW values only. Do NOT normalize or scale.
  • If a KPI cannot be measured, enter N/A and explain in Notes.
  • The same template will be re-used for each measurement cycle.
  • Return the file in .xlsx (Excel) format.
