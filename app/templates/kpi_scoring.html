Enter Best, Worst, and Actual values for each KPI. The system auto-computes a normalized 0-100 performance score. Any unit works (hours, %, ppm, $, count).

Scoring Rules

  1. Best = aspirational target (100% performance). Worst = unacceptable floor (0% performance).
  2. Direction is inferred: if Best < Worst, lower is better (e.g., cycle time). If Best > Worst, higher is better.
  3. Actual = the real measured value from operations (same unit as Best/Worst).
  4. Score is auto-computed: (Actual - Worst) / (Best - Worst) x 100, clamped to 0-100.
  5. All KPIs must be scored before the engine can run. Partial saves allowed.
